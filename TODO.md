# Дорожная карта

Четыре фишки, которых нет у Komoot / Strava / Windy. Делаем по очереди —
каждая следующая опирается на предыдущую.

Легенда: `[ ]` не начато · `[~]` в работе · `[x]` готово и проверено

## 1. Физика вместо плоских 27 км/ч — ГОТОВО

**Зачем первой:** сейчас ETA считается по фиксированной средней скорости. На
горках и против ветра это врёт на десятки минут, а от ETA зависит, какой прогноз
подставится в точку маршрута. Пока это не починено, все остальные фишки считают
погоду не на тот момент.

**Что даёт пользователю:** честное время прихода в каждую точку, цена ветра в
ваттах и минутах («сегодняшний ветер стоит тебе +14 минут»), реальный профиль
скорости по маршруту.

- [x] `shared/physics.ts` — модель мощности: качение + аэродинамика + уклон
- [x] Решение обратной задачи: по целевой мощности найти скорость (численно)
- [x] Плотность воздуха из температуры и давления, а не константа 1.225
- [x] Уклон из высот GPX со сглаживанием шума
- [x] Ограничение скорости на спуске (велосипедист тормозит, а не разгоняется)
- [x] `scoreRoute` идёт по сегментам последовательно, накапливая время
- [x] Профиль велосипедиста: масса, CdA, Crr, целевая мощность
- [x] «Цена ветра»: сравнение с той же поездкой в безветрие
- [x] Экран настроек профиля в mobile
- [x] Проверить в симуляторе и в вебе

## 2. Проскочить между дождями — ГОТОВО

**Что даёт пользователю:** сетка «задержка старта × темп». Для каждой пары
считаем, сколько километров придётся ехать под дождём. Ответ вида «выедешь на
20 минут позже или держи 29 км/ч — проедешь сухим». Обычные приложения считают
погоду в точке, а не вдоль движения, поэтому такого не умеют.

- [x] `shared/dodge.ts` — перебор задержек старта × целевых мощностей
- [x] 15-минутные осадки вместо почасовых — иначе сдвиг на 15 и 45 минут
      давал бы одинаковый ответ
- [x] Ускорение расчёта: предрасчёт геометрии и O(1) выборка из рядов
      прогноза (293 мс → 15 мс на сетку)
- [x] Применение варианта по нажатию на клетку
- [x] Тепловая карта результата (мокрые км по каждой комбинации)
- [x] Выбор лучшего варианта и текстовый совет
- [x] Экран/панель в mobile
- [x] Проверить в симуляторе

## 3. Куда ехать сегодня

**Что даёт пользователю:** без GPX. Точка старта и желаемая дистанция → роза
ветров по 16 направлениям: куда ехать, чтобы туда против ветра, а обратно с
ветром в спину. Любимый приём шоссейников, но нигде не автоматизирован.

- [ ] Прогноз на кольцо точек вокруг старта одним запросом
- [ ] `shared/directions.ts` — оценка out-and-back по каждому румбу
- [ ] Учёт дождя в оценке направления
- [ ] Виджет розы ветров в mobile
- [ ] Проверить в симуляторе

## 4. Живой режим в поездке

**Что даёт пользователю:** во время езды — «ливень накроет через 12 минут»,
«переждёшь 8 минут — ячейка уйдёт». Самое тяжёлое: нужны разрешения,
геолокация и экстраполяция движения ячеек по кадрам радара.

## Заметки

- Сетка «проскочить между дождями» не монотонна: бывает, что ехать **медленнее**
  выгоднее — ячейка успевает уйти вперёд. Проверено на Дублине: при задержке
  105 мин 145 Вт дают сухой маршрут, а 225 Вт — 9 км под дождём.
- Замкнутая петля при постоянном ветре всегда медленнее безветрия
  (проверено численно: 20 км/ч на кольце 360 км стоят +40 мин).
